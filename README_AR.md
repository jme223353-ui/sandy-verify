# بوابة تفعيل مقاطعة ساندي

موقع مستقل، وليس ريسورس FiveM. لا تضعه داخل resources في Nitrado. يحتاج استضافة Node.js 24 مع HTTPS، أو VPS يدعم Docker.

الآيديات جاهزة في .env.example: السيرفر 1555677916426141919، رول الموافقة 1555679995471462410، وروم الرجوع 1555681174154645695.

## إعداد Discord
1. افتح https://discord.com/developers/applications وأنشئ تطبيقًا باسم مقاطعة ساندي.
2. في Bot، جهّز البوت وانسخ التوكن إلى DISCORD_BOT_TOKEN داخل .env على الاستضافة فقط. لا ترسله في الشات.
3. من OAuth2 انسخ Client ID وClient Secret إلى DISCORD_CLIENT_ID وDISCORD_CLIENT_SECRET.
4. أضف Redirect URI مطابقًا للرابط الفعلي: https://YOUR-DOMAIN/auth/callback.
5. أضف البوت لسيرفرك عبر OAuth2 URL Generator باستخدام scope bot وصلاحية Manage Roles فقط. لا يحتاج Administrator ولا قراءة رسائل أو تشغيل اتصال Gateway.
6. ارفع رتبة البوت فوق رول الموافقة في ترتيب الرولات. تأكد أن رول الموافقة يسمح للمستخدم برؤية قنوات السيرفر المطلوبة.

## التشغيل
انسخ .env.example إلى .env، ثم أدخل بيانات التطبيق وPUBLIC_URL (رابط موقعك HTTPS).
راجع شروط terms.json وعدّلها لشروط سيرفرك الفعلية، ثم غيّر approved إلى true وTERMS_APPROVED=true. الشروط الحالية مسودة، والمنح الفعلي يتوقف حتى اعتمادها.
شغّل: npm start
للمعاينة المحلية فقط: npm run dev ثم افتح http://localhost:3000.
للاختبار: npm test

## نشر الرابط في روم الشروط
بعد تشغيل الموقع الحقيقي، انسخ هذه الرسالة إلى الروم 1555681174154645695:
«لتفعيل حسابك، افتح رابط الموقع وسجّل بحساب Discord، ثم اقرأ الشروط ووافق عليها: https://YOUR-DOMAIN»

يعرض الموقع صورة المستخدم وصورة السيرفر الفعلية بعد الإعداد. المستخدم يجب أن يكون عضوًا في السيرفر. يمنح الرول المحدد فقط بعد موافقة صريحة، ويسجل الآيدي ووقت الموافقة ونسخة الشروط في data/verification.sqlite. يحتفظ بملف data عند تحديث الموقع، ولا تخزّن .env في مستودع عام.

الاختبارات تستخدم Discord وهميًا ولا تمنح أي رول حقيقي. صورتا preview.png وpreview-consent.png معاينة للواجهة، وليستا إثبات ربط فعلي.
